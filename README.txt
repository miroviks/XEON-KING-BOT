DRGVCHGANG Bot v4

Установка/запуск:
1) python -m venv .venv
2) Активируйте venv
   Windows: .venv\Scripts\activate
   macOS/Linux: source .venv/bin/activate
3) pip install -r requirements.txt
4) Скопируйте .env.example -> .env и вставьте BOT_TOKEN
5) python app.py

Важно:
- НЕ кладите токен в config.txt.
- Не удаляйте папку data/, если хотите сохранить базу.
